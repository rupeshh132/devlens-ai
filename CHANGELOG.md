# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial Release

### Added
- GitHub OAuth2 authentication via Spring Security.
- JWT-based authorization and session management.
- Backend Repository synchronization and data hydration API.
- Dashboard API aggregating project metrics.
- Asynchronous analysis engine running in background threads.
- Server-Sent Events (SSE) stream for real-time analysis progress updates.
- Basic PDF reporting generation.
- Full React 18 frontend with code-split routing.
- React Query caching and state management.
- Production-ready Docker Compose orchestration.
- Initial security hardening and query performance optimizations.
